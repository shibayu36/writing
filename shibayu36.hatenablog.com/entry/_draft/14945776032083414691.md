前回の記事で『つくりながら学ぶ！LLM 自作入門』を理解するために、1層1ヘッドの最小構成のGPTで日本語を学習・生成させてみた。

[https://blog.shibayu36.org/entry/2026/09/28/173000:embed:cite]

次のステップとしてTransformerブロックを4層にしたもので学習させて文章生成してみた。生成精度が上がっただけでなく、層ごとのモデルの中身を可視化すると、最後の層で抽象度の高い概念を扱っていそうな様子が見えて面白かったので書いておく。

4層まで実装した時点のcommitは以下のリンク。gpt.pyのOneHeadGPTがTransformerBlockをn_layers個積んでいるだけで、層数はconfig.pyで切り替えられる。

https://github.com/shibayu36/learn-llm/tree/d6d7533a87bc22a025edc5117c86c8d4dad3e495/llms-from-scratch

### 4層にすると生成がだいぶそれっぽくなった
埋め込み128次元・5,000stepで4層にしたモデルを学習させてみた。config.pyの設定はこちら。

```python
self.d_model: int = 128        # 1tokenを表すベクトルの次元数
self.n_layers: int = 4         # 積むTransformerブロックの数
self.context_length: int = 256 # 一度にモデルへ入れる最大token数
self.steps: int = 5000         # パラメータを更新する回数
self.learning_rate: float = 0.001
```

学習と生成のコマンドはこんな感じ。

```bash
# 学習する
uv run main.py train --run-name l4h1
# 学習したモデルで文章生成をする
uv run main.py generate "日本の首都は" --run-name l4h1 --temperature 0
```

学習の様子。東京都が出てきたり、「日本の国民の国民主党の国際的な議論を行っています」のような長めの文が出てくるようになった。

```text
step 1000: 、「200000000000000000000000000000…
step 2400: 、「東京都」の「東京都」の「東京都」の「東京都」の「東京都」の…
step 4000: 、「日本人の人がいいます」ということができます。 「このように、「日本では、…
step 5000: 、日本では、日本では、日本の国民の国民主党の国際的な議論を行っています。…
```

同じ条件で1層と4層を比較した[^1]。両方とも「日本の首都は」とは関係ない文章を生成しているが、4層の方が比較的文の形をした文章が出てくるようになった。またそれっぽいところで改行も入れるようになった。


temperature 0.8で「プログラミングを学ぶには、」を生成させると、4層はアプリ・サイトなどプログラミング寄りの単語を選ぶようになっていた。


### 層ごとに中身を見ると、4層目で抽象度の高い概念が表現されるようになった
4つの層がそれぞれ何をしているのかを知りたくて、各Transformerブロックの出力（hidden state）を2つの方法で観察した。

- logit lensという手法で見る。その層のhidden stateを最終のLayerNormと出力層に通し、その時点で次の文字を何と予測しているかを見る
- 近い文脈を探す。学習に使っていない検証用の文章を通したときの同じ層のhidden stateと比べ、似ているものを上位10件、前後の文字つきで並べる。ある文字がその層では何の仲間として扱われているかが分かる

観察対象は「◯行」の「行」にした。銀行・旅行・実行・発行のように、前の文字で意味が変わるからだ。次の4文を入れて、それぞれの「行」の位置のhidden stateを層ごとに見た。

- お金を預けたい。銀行の口座を開く。
- 休暇を楽しもう。旅行の予定を立てる。
- 処理が完了した。実行の結果を確認する。
- 書類を受領した。発行の日付を確認する。

次のコマンドで可視化したHTMLを生成して観察してみる。

```bash
# 各層のhidden stateを観察するHTMLを作る
uv run main.py visualize-hidden-states --run-name l4h1
open runs/l4h1/hidden_states.html
```

logit lensなら、このようにある層まで積み重ねた時点での次の予測確率を可視化してくれる。画面のLayerを切り替えれば、その層の予測確率が見られる。

近い文脈を探す可視化だと、このように検証データの中で似ている文脈を探し、どのような文脈として解釈されているかをイメージできる。

[f:id:shiba_yu36:20260928134958p:plain]

特におもしろかったのは、1層目と4層目で近い文脈の候補がはっきり変わったことだ。

1層目は、どの文でも「中央銀行」「団体旅行」「宇宙飛行士」のような「行」を含む文脈がほぼ同じ候補で並ぶ。銀行・旅行・実行・発行の4文で近傍にほとんど差がなく、まだ「行」という文字を見ているだけのようだ。2層目・3層目もほぼ同じで、1層目と大きな違いは見えない。

[f:id:shiba_yu36:20260928143713p:plain:w400]

4層目になると「金融」「出費」「借金額」のように、入力した熟語とは別の単語が上位に入ってくる。

[f:id:shiba_yu36:20260928140143p:plain]

4層目の近傍から、入力した熟語そのもの（銀行・旅行・実行・発行）以外を抜き出すとこうなる。

| 文 | 同じ熟語以外の近傍（類似度） |
|---|---|
| お金を預けたい。銀行 | 金**融**商品(0.58) 出**費**(0.57) 借金**額**(0.57) 金**融**ショ(0.56) |
| 休暇を楽しもう。旅行 | 進**行**(0.79) 設**備**(0.71) 移**行**(0.71) 収**入**(0.70) 移**動**(0.69) |
| 処理が完了した。実行 | 進**行**(0.78) 受**信**(0.67) 設**備**(0.67) 移**行**(0.66) |
| 書類を受領した。発行 | 進**行**(0.76) 移**行**(0.72) 審**査**(0.66) 発**売**(0.66) 放**送**(0.66) |

銀行はお金系、旅行は移動系、実行は進むっぽい系、発行はちょっと書籍っぽい系の単語に近づいている。3層目までは「行」という文字しか見ていなかったのが、4層目では「今どんな話題の中にいて次に何が来そうか」を理解できていそうな雰囲気が見えて、これは非常に面白かった。

### まとめ
4層に発展させたら生成がそれっぽくなっただけでなく、3層目までは文字そのものを見ていたのが4層目で話題に近い単語を捉えていそうな雰囲気まで観察できた。層ごとの解釈は素人の推測も混ざっているので、間違っていたらツッコミをもらえると嬉しい。次はattention headを複数にして、書籍の3章のMulti-Head Attentionに戻って理解を進めていきたい。
