CLIツールのREADME用のデモGIFを画面録画で手撮りするのは面倒だ。先日[herdrのplugin](https://github.com/shibayu36/herdr-equalize-panes)を作った時、VHSを使ったらこれが劇的に楽になった。

VHSはcharmbracelet製のツールだ。公式には「Write terminal GIFs as code for integration testing and demoing your CLI tools」と説明されている。つまり、CLIツールのデモ用に、ターミナル操作のGIFをコードとして書けるツールだ。tapeというファイルに操作を書き、`vhs demo.tape`を実行すると、その操作を再現したGIFができる。

[https://github.com/charmbracelet/vhs:embed:cite]

今回README用に書いたtapeはこれ（一部整形している）。

```
Output demo.gif

Set Shell "bash"
Set FontSize 16
Set Width 960
Set Height 620

# herdrの起動は録画から隠す
Hide
Type "export HERDR_CONFIG_PATH=$PWD/tmp/demo-config.toml; clear; herdr --session vhs-demo"
Enter
Sleep 4s
Show

Sleep 1.5s

# 右に分割 -> 2等分になる
Ctrl+T
Sleep 400ms
Type "3"
Sleep 2s

# さらに右に分割 -> 3等分になる
Ctrl+T
Sleep 400ms
Type "3"
Sleep 2.5s

# 右端のペインを閉じる -> 2等分に戻る
Type "exit"
Sleep 500ms
Enter
Sleep 2.5s
```

実行するとこのGIFができる。

[f:id:shiba_yu36:20260822203008g:plain]

見てのとおり、tapeはキー操作と`Sleep`を並べるだけ。`Hide`〜`Show`の間は録画に映らないので、起動などの準備部分は隠せる。

そして録画がコードになっていると、GIF作りをAIに丸ごと任せられる。実際このtapeはClaude Codeに書かせて、`vhs`での撮影までやらせた。「シェルのプロンプトが見づらいから$だけにして」と伝えればtapeを直して撮り直してくれる。手撮りだと辛い撮り直しが、コードなら一瞬で終わって最高。

READMEにデモGIFを載せたい人は、VHSをぜひ試してみてほしい。
